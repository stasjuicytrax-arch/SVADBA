## Шаг 1. Открыть терминал в папке проекта
1. Откройте папку `svadbanew` в Проводнике.
2. Кликните в адресную строку Проводника, сотрите путь, напишите `powershell` и нажмите Enter.
   Откроется синее/чёрное окно, уже в нужной папке.

## Шаг 2. Скачать фотографии (один раз)
Вставьте в терминал (правый клик = вставить) и нажмите Enter:
```powershell
powershell -ExecutionPolicy Bypass -File .\download-assets.ps1
```
Побегут строки `OK …`. В конце — `Done. downloaded: 230 …`. Появится папка `assets` с подпапками по блокам и галереями пар.
Если есть `FAIL` — просто запустите команду ещё раз, скачаются только недостающие.

## Шаг 3. Git — «точки сохранения» (очень советую)
```powershell
git init
git add .
git commit -m "ТЗ и материалы"
```
Теперь после каждого удачного этапа можно сохраниться, а если что-то сломалось — откатиться.

## Шаг 4. Запустить Claude Code
```powershell
claude
```
Внутри Claude наберите `/` — в списке должны быть `impeccable` и `design-taste-frontend`.
Если их нет — выйдите (`/exit`) и установите в папке проекта:
```powershell
npx impeccable install
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

## Шаг 5. Строим сайт по этапам
Откройте `docs/PROMPTS.md`, копируйте **Этап 1** и вставляйте в Claude. Дальше цикл на каждый этап:

1. Вставить промпт этапа → Claude работает (на вопросы о разрешениях отвечайте «Yes»).
2. Посмотреть результат: откройте `index.html` двойным кликом (в Chrome). После каждой правки Claude — нажмите F5 в браузере.
3. Не нравится — пишите Claude простыми словами: «заголовок в hero слишком мелкий, сделай в 2 раза крупнее» или используйте `/impeccable critique` и `/impeccable polish`.
4. Нравится — сохраниться (во втором окне PowerShell или попросите Claude сделать коммит):
   ```powershell
   git add .
   git commit -m "Этап 2 готов"
   ```
5. Следующий этап.

## Шаг 6. Продолжить на следующий день
```powershell
claude --continue
```
Claude продолжит с того же места.

## Если что-то пошло не так
- Откатить последние изменения до последнего сохранения: `git restore .`
- Ошибка в терминале — скопируйте её целиком и вставьте Claude со словами «вот ошибка, почини».

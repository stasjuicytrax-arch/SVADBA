# Готовые промпты для Claude Code (копируй по одному)

Каждый промпт = один этап. Вставил → дождался → посмотрел в браузере → сделал коммит → следующий.

---

## Этап 1 — каркас
```
Прочитай CLAUDE.md и все файлы, которые там указаны, включая картинки в Referens. Используй скилл design-taste-frontend.
Сделай сайт БЕЗ сборки и без npm: index.html + папки css/ и js/, GSAP и Lenis подключи через CDN jsDelivr.
Сайт должен открываться двойным кликом по index.html.
Сделай только фундамент: tokens.css по DESIGN.md (цвета, шрифты, шкала, радиусы), подключи шрифты, базовые стили,
и пустые секции 00–15 в правильном порядке с якорями и заголовками из ТЗ.
```

## Этап 2 — шапка, hero, бегущая строка, фото-лента, «В титрах» (блоки 00–04)
```
Сверстай блоки 00–04 из docs/TZ.md строго по DESIGN.md и референсу Referens/1.jpg.
Hero — «экран» со шторкой-интро, линейка-таймкод, liquid glass навигация и мини-карточки. Тексты дословно из ТЗ.
В конце сделай pre-flight проверку taste skill.
```
После: `/impeccable critique hero` → `/impeccable polish` для того, что он найдёт.

## Этап 3 — «Особый фильм», «Не ходим в кадре», форма №1 (блоки 05–07)
```
Сверстай блоки 05–07 из docs/TZ.md. Двухцветные заголовки лесенкой с фото-пилюлями (DESIGN.md §3),
тёмная секция с веером фото, форма-«билет». Форма пока без отправки — только валидация и красивое состояние успеха.
```

## Этап 4 — портфолио и галереи (блок 08)
```
Сверстай блок 08 «Портфолио»: bento-сетка 10 пар и полноэкранный лайтбокс-галерея по DESIGN.md §7.
Фото из assets/galleries/<пара>/. Поддержи старые хэши (#nadezdadamir и др.), свайп, клавиатуру, lazy-loading.
```
После: `/impeccable animate portfolio` если анимации скучные.

## Этап 5 — «Почему настоящие», отзывы, этапы (блоки 09–11)
```
Сверстай блоки 09–11: sticky-сплит с меняющимся фото, отзывы двумя едущими колонками, этапы — закреплённая
горизонтальная раскадровка на GSAP ScrollTrigger (на мобиле вертикальный таймлайн).
```

## Этап 6 — стоимость, FAQ, лента, футер, попап (блоки 12–15 + попапы)
```
Сверстай блоки 12–15 и попап-форму №2 из docs/TZ.md. Футер с реквизитами в виде «финальных титров».
Все кнопки «Написать нам» / «Связаться с нами» открывают попап.
```

## Этап 6.5 — законы РФ (обязательно)
```
Прочитай docs/LEGAL.md и приведи сайт в соответствие, ничего не пропуская:
1. Шрифты скачай в fonts/ (woff2, кириллица+латиница, только нужные начертания) и подключи через @font-face — убери Google Fonts.
2. GSAP, ScrollTrigger и Lenis скачай в js/vendor/ и подключи локально — убери все внешние CDN.
3. Создай страницы politika.html и soglasie.html по черновикам из LEGAL.md §4–5 в стиле сайта.
4. Во всех формах — пустой обязательный чекбокс согласия со ссылками на эти страницы, без галочки кнопка неактивна.
5. Cookie-баннер по §2.5 (три равные кнопки, настройка категорий, Метрика грузится только после согласия, ссылка «Настройки cookie» в футере).
6. Все подписи на русском («IG» → «Инстаграм*», «TG» → «Телеграм»), сноска про Meta в футере.
7. Проверь код поиском: не должно остаться ссылок на fonts.googleapis.com, gstatic, jsdelivr, cdnjs, google-analytics, googletagmanager, recaptcha.
В конце дай список того, что должен сделать заказчик (раздел 3 LEGAL.md).
```

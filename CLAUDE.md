# CLAUDE.md — инструкция для Claude Code

Проект: новый сайт свадебного агентства «В титрах» (редизайн https://help-wedding.ru/).
Пользователь — начинающий разработчик. Объясняй коротко и по-русски, что ты сделал и как это проверить.

## Прочитай перед любой работой (в этом порядке)
1. `PRODUCT.md` — кто клиент, аудитория, цели.
2. `DESIGN.md` — палитра, шрифты, liquid glass, анимации, анти-слоп.
3. `docs/TZ.md` — порядок блоков, ДОСЛОВНЫЕ тексты, картинки для каждого блока.
4. `Referens/1.jpg`, `2.jpg`, `3.jpg` — визуальные референсы. Открой и посмотри их, не пропускай.

## Скиллы
- **Impeccable** (`/impeccable …`) — контекст берёт из `PRODUCT.md` и `DESIGN.md` в корне. Используй для оценки и доводки: `critique`, `audit`, `polish`, `typeset`, `layout`, `animate`, `adapt`, `optimize`, `overdrive`.
- **Taste Skill** (`design-taste-frontend`) — используй при создании каждого нового блока: redesign-протокол, запреты на шаблонный дизайн, pre-flight чек перед сдачей.
Если скиллы противоречат друг другу — приоритет у `DESIGN.md` этого проекта.

## Жёсткие правила
- Тексты — только из `docs/TZ.md`, дословно. Не сочинять новые заголовки/отзывы/цифры. Если для дизайна нужна подпись, которой нет в ТЗ, — используй фразы из ТЗ или спроси.
- Порядок блоков — строго как в `docs/TZ.md` (00 → 15).
- Картинки — только из `assets/` (скачиваются `download-assets.ps1`). Не использовать стоки и сгенерированные картинки без спроса.
- Работаем ТОЛЬКО в этой папке (`svadbanew`). Другие папки на рабочем столе (в т.ч. `weddings` со старой версией) не трогать и не использовать.
- Стек БЕЗ сборки: чистые HTML + CSS + JS. GSAP (+ScrollTrigger) и Lenis подключать через `<script src="https://cdn.jsdelivr.net/npm/...">` в конце `index.html`. Никаких npm, Vite, `import` из node_modules и `type="module"` — сайт должен открываться двойным кликом по `index.html` (file://). Без React/Tailwind.
- Делаем по одному этапу за раз (см. `docs/PROMPTS.md`). После этапа: проверь, что `index.html` открывается двойным кликом без ошибок в консоли, коротко перечисли, что сделано, и предложи сделать git-коммит.
- Mobile-first. Проверяй 375px и 1440px.
- `prefers-reduced-motion` — обязательно.
